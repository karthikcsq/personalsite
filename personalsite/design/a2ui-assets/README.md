# A2UI visual asset direction

Generated illustrations should read as quiet pencil diagrams, not synthetic scenes.

- Prefer objects, mechanisms, maps, tools, and abstract systems.
- Do not generate realistic people, hands, portraits, or expressive group scenes.
- Generic faceless silhouettes, bust tokens, or crowd marks are acceptable when scale or community needs a human cue.
- Keep human markers deliberately anonymous: no facial features, hair, clothing detail, age, race, or gender cues.
- Use forest green, warm charcoal, and restrained burnt orange on transparent backgrounds.
- Avoid text, logos, interface screenshots, rounded-square icons, glossy vectors, and photorealism.
- Keep generated diagrams strictly two-dimensional: front-facing or top-down symbols, flat paper cutouts, and simple connecting lines.
- Avoid isometric views, foreshortening, cylindrical end caps, shaded thickness, cast shadows, rendered metal, and overlapping faces that imply fake depth.
- Let the host create depth through real CSS paper layering and shadows. The bitmap itself should remain flat.
- The illustration supports the answer; it should not become the answer.
